# DSH-QizhouCNC_CAM

> 由成都起舟机械科技有限公司制作，仅供研究学习使用。

一个面向 DeepSeek Harness（DSH）的 CNC 数控程序（NC / CNC / G-code）可视化与编辑插件。点开一个 NC 文件，即可在右侧面板里看到三维刀路，并进入大界面编辑器预览、修改，甚至把选中的代码片段一键引用进 DSH 对话框，让模型快速定位到具体程序段。

## 特点与功能

- **NC 刀路识别与三维显示**：自动识别 `.nc` / `.cnc` / `.gcode` 文件并解析 G-code，在面板内以三维 SVG 投影绘制刀路（切割段与快速移动段区分显示），带 XYZ 坐标轴与网格。
- **六视图 + 等轴视角**：俯视 / 前 / 右 / 后 / 左 / 仰 / 等轴，一键切换；支持拖拽旋转、Shift/右键平移、滚轮缩放、重置适配。
- **大界面 NC 编辑器**：点击文件行的 ✎ 进入编辑器，全宽预览 NC 原文，可直接修改并保存（⌘/Ctrl+S），保存后自动重新解析并刷新刀路。
- **代码引用到对话框**：在编辑器中选中若干行，点「引用到对话框」，即可把「文件 + 行号 + 代码」引用进 DSH 输入框，方便模型快速定位程序段。
- **工作区文件扫描**：自动扫描当前会话工作区，也支持「选择路径」手动添加文件夹；列表显示 NC 文件与 STEP 模型。
- **STEP 模型生成刀路**：对 `.step` / `.stp` 模型，可通过 FreeCAD CAM 生成 G-code 轮廓刀路。
- **打开文件所在位置**：一键在系统文件管理器中定位文件。

## 安装

将本目录作为 DSH 插件安装（本地链接或打包为 bundle），启用后即可在界面右侧标签栏看到 `QizhouCNC_CAM`。
