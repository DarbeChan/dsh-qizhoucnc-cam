# CNC 技能创建与使用规范（元技能）

本技能规范「如何把一个可复用的 CNC 加工方法/工具」写成标准 SKILL，确保所有技能命名统一、结构一致、可直接并入 qizhouCNC_CAM。

## 触发场景

- 用户要求「把某个加工方法/工具提炼为 SKILL」
- 用户要求「规范技能命名、方便并入 qizhouCNC_CAM」
- 需要新建或重构 CNC 领域技能时

## 输入

- 一段已跑通的加工方法（G 代码片段、伪代码、工艺参数）
- 该方法适用的设备与硬性约束（如速玛尔 3+2 / FANUC 0i-MC）

## 输出

- 一个 `cnc-<名>/SKILL.md` 技能目录（符合 frontmatter 规范）
- 更新 `CNC-Skills/README.md` 技能清单

## 技能目录与命名规范

### 目录结构

```
CNC-Skills/
└── cnc-<动作>-<对象>/
    └── SKILL.md
```

### 命名规则

1. 目录名 = `name` 字段，**小写 + 连字符 + `cnc-` 前缀**。
2. 命名 = `cnc-` + `动词-名词`（如 `cnc-thread-mill`）或纯名词（如 `cnc-fanuc-post`）。
3. 与 qizhouCNC_CAM 现有技能同前缀（`cnc-process-card` / `cnc-stock-diff` / `cnc-auto-annotate`）。

### frontmatter（必须）

```yaml
---
name: cnc-<名>                    # 必须与目录名一致
description: <一句话>             # 含"当用户…时使用"，可被路由匹配
---
```

### SKILL.md 正文固定章节

按顺序写以下章节，标题用 `##`：

1. `#` 标题
2. 一句话说明
3. `## 触发场景` — 何时用
4. `## 输入` — 参数清单
5. `## 输出` — 产物
6. `## 生成规则` — 核心：参数化伪代码 / 公式（最重）
7. `## 关键约束` — 设备限制、安全红线（硬性）
8. `## 示例`（可选）

## 生成规则写作要点

- 用**参数化伪代码**而非只给结论：变量名、公式、循环都写清楚，便于复用和替换具体数值。
- 明确**单位**（mm、rpm、mm/min）与**坐标约定**（G54、A 绕 X、C 绕 Z）。
- 把「设备硬性约束」从「可调参数」分开，前者写进 `关键约束`，后者写进 `输入`。

## 并入 qizhouCNC_CAM

1. 把 `cnc-<名>/` 目录复制到插件源码 `dsh-qizhoucnc-cam-main/skills/` 下。
2. `name` 与 `description` 由 DSH 自动注册。
3. 用 `skill` 工具按名加载，即可在会话中调用。

## 关键约束

- **一个技能只讲一件事**（单一职责）：如「螺纹铣」与「失圆补偿」分开，不要混在一个 SKILL 里。
- **description 可路由**：必须写清触发词（"螺纹铣""啄钻""失圆"等），否则自动匹配不到。
- **不写死具体工件数值**：技能里用变量（孔径、深度、坐标），具体数值留给调用时的工艺卡/程序。
- 每次新增技能后，**同步更新 README.md 的技能清单表**。
