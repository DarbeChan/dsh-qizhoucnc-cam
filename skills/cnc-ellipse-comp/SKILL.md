# 失圆补偿（椭圆逼近 / Ellipse Compensation）

设备铣圆时 X/Y 方向尺寸失圆（系统性的轴比例/背隙问题），无法用刀具半径补偿解决，必须在程序层面用**椭圆轨迹替代正圆**来抵消失圆。失圆的方向和量**以实测为准**，不能想当然假设某个方向欠切。

## 触发场景

- 设备铣圆 X 方向比 Y 方向小（失圆）
- 需要给铣孔/铣牙做椭圆补偿
- 设备不支持 G65 宏，需内联 G01

## 输入

| 参数 | 含义 | 示例 |
|---|---|---|
| R | 理论刀心轨道半径（正圆） | 0.55 |
| ΔDx, ΔDy | X/Y 实测直径偏差（实测−目标，过切为正） | 由试铣测得 |
| n_pt | 每圈逼近点数 | 36~72 |

## 输出

- 内联 G01 椭圆逼近轨迹（逐点 X/Y 坐标）

## 生成规则

### 1. 椭圆半轴（以实测为准）

```
rx = R - ΔDx/2        # X 半轴（ΔDx = X 实测直径 − 目标直径，过切为正）
ry = R - ΔDy/2        # Y 半轴（ΔDy = Y 实测直径 − 目标直径，过切为正）
```

> 先按正圆轨道 R 试铣一刀，实测 X/Y 两向孔径，算出各向直径偏差 ΔD（实测−目标，过切为正、欠切为负），再反向减掉。**补偿方向和量以实测为准，禁止套固定假设**（如「X 恒欠切 0.2、恒 +0.1」）。

> 实测案例：T4 φ2.0 扩孔 φ2.8，实测 X=3.1 / Y=2.87 → ΔDx=+0.3、ΔDy=+0.07，R=0.4 → rx=0.4−0.15=0.35、ry=0.4−0.035=0.365。注意此处 X 反而过切，与「X 恒欠切」的早期假设相反。

### 2. 椭圆逐点逼近（内联 G01，无宏）

```
for k in 0..N:
    θ = 2π * k / N
    X = cx + rx * cos θ
    Y = cy + ry * sin θ
    G1 X{x} Y{y}
```

### 3. 椭圆螺旋（铣牙/铣孔轴向进给）

```
for k in 0..总点数:
    θ = 2π * k / 每圈点数
    z = z0 + (z1-z0) * k / 总点数
    G1 X{cx+rx·cosθ} Y{cy+ry·sinθ} Z{z}
```

## 关键约束

1. **设备不支持宏程序 B（G65）**：不能用 G65 宏子程序做椭圆，必须**内联 G01 逐点展开**。
2. 内联展开导致程序体积膨胀（几百 KB），需提醒用户用 **DNC / CF 卡** 运行大程序。
3. 补偿方向/量：**以实测为准**。先试铣测出 ΔDx、ΔDy，再 rx=R−ΔDx/2、ry=R−ΔDy/2。禁止沿用固定方向/固定量（曾因套「X 恒 +0.1」导致 X 反而过切）。
4. 叠加螺纹尺寸修正时：先核实刃径实际值，按 R=(大径−实际刃径)/2 算满牙轨道，再单独叠加失圆补偿；不盲目叠固定补偿量（曾因「刃径按 3.0 算又 +0.08」导致螺纹过松）。
5. 逼近点数：每圈 ≥ 36 点保证圆度；孔精度高取 72 点。

## 示例

铣牙 M5，R=0.55，失圆补偿 +0.1 → rx=0.65, ry=0.55：

```
每圈 36 点，螺旋 Z1→Z-15：
G1 X{cx+0.65·cosθ} Y{cy+0.55·sinθ} Z{z}
```
