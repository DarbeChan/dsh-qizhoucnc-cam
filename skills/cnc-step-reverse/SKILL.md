# STEP 模型几何逆向（Step Reverse Engineering）

从 STEP/STP 文件解析几何，提取孔、圆柱面、平面的精确直径/轴心/位置，反解出加工所需的尺寸参数。用于无图纸或需核验图纸尺寸时。

## 触发场景

- 需要从 STEP 反解孔径、孔位、外形尺寸
- 识别模型的圆柱面（孔/外圆）与平面特征
- 布尔差（毛坯−成品）之外，还要精确孔位坐标

## 输入

- STEP/STP 文件路径
- （可选）想要提取的特征类型：孔 / 外圆 / 平面 / 槽

## 输出

- 每个圆柱面的：中心坐标、半径、直径、轴向（X/Y/Z）
- 每个平面的法向与包围盒
- 工件整体包围盒（X/Y/Z 范围）

## 生成规则（解析要点）

### 1. STEP 实体结构

- `CARTESIAN_POINT`：顶点坐标。
- `B_SPLINE_SURFACE(du, dv, 控制点网格)`：曲面；`du=2, dv=1` 表示 u 方向是圆（9 控制点）、v 方向是拉伸（2 点）。
- `RATIONAL_B_SPLINE_SURFACE`：带权重的曲面，权重 0.7071 的控制点在圆外。
- 复合实体 `#N=( BOUNDED_SURFACE() B_SPLINE_SURFACE(...) ... )`：曲面内嵌在括号里，不是独立单行。

### 2. 圆拟合（关键坑）

- **有理圆弧只取权重=1 的控制点**（偶数索引）拟合圆，才能得到精确半径；把权重 0.7071 的点一起拟合会半径偏大。
- 用最小二乘 3D 圆拟合（先 SVD 求平面法向，再在平面内拟合圆心/半径）。

### 3. 圆柱面分类

- 圆拟合得到：中心、半径、平面法向。
- 轴向 = v 方向（拉伸方向）或平面法向。
- 按半径区分：小半径（<10）是孔/内孔，大半径是外圆。

## 关键约束

1. **AUTOMOTIVE_DESIGN_CC2 schema** 的曲面常是复合实体，解析器必须处理括号嵌套，不能只按单行 `#N=` 抓取。
2. **有理圆弧拟合必须排除 0.7071 权重点**，否则半径系统性偏大。
3. 反解结果用于编程前，**必须与图纸或对刀实测核对**（NURBS 反解可能有朝向/基准差异）。
4. 模型若被用户旋转过，反解坐标会随模型姿态变化，需结合 `cam_get_model_pose` 换算真实装夹坐标。

## 示例

成品 STEP 反解结果（分体软轴辊轮）：

```
圆柱面: 中心(-5.99,16.44,-7.00) R=2.6 D=5.2 轴=Z   ← M6 底孔/扩孔
        中心(0,0,-6.00) R=18.0 D=36.0 轴=Z          ← 内孔
外圆:   R=24.0 D=48.0（有理圆弧 weight-1 点拟合）
包围盒: X[-34,30] Y[-27,32] Z[-19.5,7.5]
```
