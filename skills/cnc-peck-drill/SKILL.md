# 啄钻 / 钻孔（G73 / G81）

用麻花钻或定心钻打孔。深孔用 G73 啄钻（分段退屑），浅孔可用 G81。

## 触发场景

- 钻底孔、打定心孔、钻深孔
- 用户明确「G73 啄钻」「安全高度 Z2」「结束 Z30」

## 输入

| 参数 | 含义 | 示例 |
|---|---|---|
| cx, cy | 孔中心坐标 | X0, Y-18.05 |
| z_end | 孔底 Z | Z-15 |
| r_plane | 安全平面 R（快速接近面） | 2.0 |
| q | 每次啄钻深度 Q | 2.0（深孔 3.0） |
| F | 进给 | 180 |
| S | 转速 | 2500 |

## 输出

- G73 啄钻循环段

## 生成规则

```
G0 X{cx} Y{cy}                     # 定位孔心
G0 Z{r_plane}                      # 降到安全平面
G98 G73 X{cx} Y{cy} Z{z_end} R{r_plane} Q{q} F{F}
G80                                # 取消循环
```

> 多孔：同一平面多个孔，用 `G98` 抬到初始面（或 `G99` 抬到 R 面），循环体只重复 `X..Y..` 坐标行，最后 `G80`。

## 关键约束

1. **啄钻 Q 值**：深孔钻 Q 取 2~3mm，铝材可偏大、钢/不锈钢偏小。
2. **R 平面**：必须高于工件表面（如 R2 或 R3），避免快速进给撞件。
3. **深孔（深径比 > 5）必须 G73 分段退屑**，不可一次钻到底，防止排屑不良断钻。
4. 孔深到位后 `G80` 取消循环，再抬刀到安全高度。
5. 姿态切换前先抬刀到安全高度或机械零。

## 示例

G73 啄钻 φ4.5，孔深 Z-15，安全 R2，Q2：

```
G0 X0.000 Y-18.050
G0 Z2.0
G98 G73 X0.000 Y-18.050 Z-15.000 R2.0 Q2.0 F180
G80
```
