# FANUC 后处理骨架（3+2 五轴）

生成 FANUC 系统 G 代码的固定骨架：程序头尾、换刀、姿态切换、回零、长度补偿的顺序与写法。这是所有具体加工技能（铣削/钻孔/螺纹）的公共框架。

## 触发场景

- 生成任何 FANUC 系统 NC 程序时（骨架 + 头尾）
- 组织换刀、A/C 姿态切换、坐标系切换的顺序
- 处理 A 轴回零、Z 轴回零、长度补偿

## 输入

| 参数 | 含义 | 示例 |
|---|---|---|
| WCS | 工件坐标系 | G54 / G55 / G56 |
| pose | 姿态 A/C | A90 C0、A0 C20 |
| T_no | 刀号 | 1~5 |
| H_no | 长度补偿号 | 同刀号 |
| S | 转速 | 4500 |
| clear_z | 安全高度 | 20 / 30 |

## 输出

- 程序头（% + O 号 + 注释）
- 换刀 + 姿态定位块
- 程序尾（回零 + M30 + %）

## 生成规则（固定写法）

### 1. 程序头

```
%
O0001
( <标题> )
( <材料/设备/规则注释> )
```

### 2. 换刀 + 姿态定位（关键顺序：切姿态 → 动 Y → 动 Z）

```
M5                     # 换刀前停主轴（避免带转速换刀 + 消除冗余能耗）
N{no*10} T{no} M6      # 换刀
G91 G28 Z0             # Z 先回机械零
G90 {WCS}              # 切坐标系
G0 A{pose.A}           # 摆 A
G0 C{pose.C}           # 摆 C（0~360）
M3 S{speed}            # 主轴正转（从 0 升到目标转速）
G0 Y0.                 # 先动 Y
G0 G43 H{no} Z{clear}  # 再动 Z（激活长度补偿）
```

> **顺序不可颠倒**：
> 1. 换刀前必须先 `M5` 停主轴——否则主轴带着上一把刀的转速换刀，换刀后 `M3 S新转速` 会表现为「转速先高后降」的冗余能耗。
> 2. 必须先摆好 A/C 姿态，再激活 G43 长度补偿（A 摆角会改变补偿方向）。

### 3. 程序尾

```
M5
G91 G28 Z0             # Z 回机械零
G90 G0 A0              # A 回零（绝对定位，非 G28）
M30
%
```

## 关键约束（速玛尔 3+2 / FANUC 0i-MC 硬性规则）

0. **【最高优先级·断刀铁律】位置结束必须抬 Z 到安全高度**：任何加工位置（钻孔/铣孔/铣牙/铣槽）做完后，**必须先 `G0 Z安全高度` 再动其它轴**（尤其 A/C 旋转、换孔 X/Y 移动）。绝不允许 Z 停在孔底时直接 `G0 C` 旋转或横移——会在孔内横切撞刀（2026-11-22 分体软轴辊轮已因此断刀一次）。生成器的每个辅助函数（peck/bore/thread）末尾必须内联 `G0 Z{clear_z}`。
1. **换刀前必须 `M5` 停主轴**：不带转速换刀，换刀后 `M3 S` 从 0 升到目标转速，避免「转速先高后降」的冗余能耗。
2. **A 轴回零用 `G90 G0 A0`，不用机械回零 `G28 A0`**（设备要求绝对定位回零）。
3. **Z 轴回零可用 `G91 G28 Z0`**（机械回零）。
4. **A 轴范围 0~90°**：背面/对面不能写 A 负角，用 C 转 180/270 实现。
5. **C 轴用 0~360° 表达**：负角转正，如 C-90 → C270、C-20 → C340。
6. **冷却液外置，程序内不写 M8/M9**（除非用户明确要求）。
7. **切姿态前必须先抬刀回机械零**（`G91 G28 Z0`），避免撞件。
8. **同刀连续多工序**：只去掉第二次的 `T? M6`，**保留 `G91 G28 Z0`**（切姿态前仍要回零）。
9. **每个独立程序只有一个 O 号、一个 M30**；多工序用 `M1` 分隔。
10. **总程序（连续加工）工序间不插 M1**，避免选择性停止开关导致的每段停顿；需人工检查的点改用单个 `M0`（程序停止）而非每段 M1。
11. 设备**不支持宏程序 B（G65）**，补偿/循环必须内联 G01 展开。

## 编程完成后必做校验（强制流程，不可跳过）

生成任何 NC 程序后，**交付前必须逐项校验并评估撞刀风险**，这是编程流程的必要收尾环节：

### 1. 抬刀安全校验（最高优先级）

- 逐个检查每个 `G0 A` / `G0 C` / `G0 X` / `G0 Y` 移动指令，确认其**前一行 Z 已在安全高度以上**（`G0 Z安全高度` 或 `G91 G28 Z0`）。
- 重点盯「加工位置切换」和「姿态旋转」衔接处：孔与孔之间、铣牙结束转 C 轴换孔、切姿态前。
- 铁律：**任何位置做完 → 抬 Z → 才能动其它轴**。

### 2. 撞刀风险清单

| 风险点 | 检查项 |
|---|---|
| 换刀 | 换刀前有 `M5`？Z 已回机械零？ |
| 切姿态 | A/C 旋转前 Z 已抬到安全高度？ |
| 快速定位 | G0 快速移动路径上是否有夹具/凸台/已加工面干涉？ |
| 下刀 | 螺旋/啄钻下刀点是否在孔中心？刀径 < 底孔？ |
| 长度补偿 | G43 H 号与当前刀号一致？ |
| 深度 | 每孔 Z 终点是否超深（撞盲孔底/夹具）？ |
| 姿态范围 | A∈[0,90]、C∈[0,360]，无负角？ |

### 3. 校验通过标准

- 每道工序（或每把刀调试程序）**单独上机空跑/单段校验**，确认无撞刀后再合并跑总程序。
- 校验 OK 前不合并总程序；校验发现问题，回到生成器改参数重跑，再校验。

### 4. 输出到工艺卡的备注

在工艺卡「注意事项」中明确写出：**本次程序已逐项校验，撞刀风险评估结论 + 需人工现场确认的点**（如夹具干涉、对刀基准）。

## 示例

换刀 T3、G56、姿态 A90 C340（C-20 正角表达）：

```
M5
N30 T3 M6
G91 G28 Z0
G90 G56
G0 A90.0
G0 C340.0
M3 S2500
G0 Y0.
G0 G43 H03 Z20.0
```
