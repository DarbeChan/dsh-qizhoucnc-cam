# 螺旋铣孔 / 扩孔（Helical Boring）

用平底铣刀沿螺旋轨迹从底孔中心切入，逐圈扩大并轴向进给，把孔扩到目标直径。适合已钻底孔后的精扩孔。

## 触发场景

- 螺旋铣孔 / 螺旋插补扩孔
- 用户要求「用 D4 铣刀把 φ4.5 孔铣到 φ5.2」「螺旋铣」

## 输入

| 参数 | 含义 | 示例 |
|---|---|---|
| cx, cy | 孔心坐标 | X14, Y0 |
| z0, z1 | 起始/终止深度 | Z-5 → Z-10 |
| fin_d | 目标孔径 | 5.2 |
| tool_d | 铣刀直径 | 4.0 |
| F / S | 进给 / 转速 | 100 / 6000 |
| step_z | 每圈轴向进给 | 0.5 |

## 输出

- 螺旋 G01 轨迹（或 G02/G03 螺旋插补）

## 生成规则

```
R = (fin_d - tool_d) / 2          # 刀心轨道半径
G0 X{cx} Y{cy}                    # 定位孔心
G0 Z{r_plane}
G1 Z{z0} F{进刀}
G1 X{cx+R} Y{cy}                  # 径向切入到轨道
# 螺旋：轴向从 z0 到 z1，圈数 = |z1-z0| / step_z
for k in 0..圈数*每圈点数:
    θ = 2π * k / 每圈点数
    z = z0 + (z1-z0) * k / 总点数
    G1 X{cx+R·cosθ} Y{cy+R·sinθ} Z{z}
G1 X{cx} Y{cy}                    # 退回中心
```

> 注意：若设备支持，可用 `G02/G03 I-J Z` 螺旋插补一行完成；**设备不支持宏（G65）时用内联 G01 逐点展开**（配合失圆补偿）。

## 关键约束

1. **必须先有底孔**才能直接下刀（刀径 < 底孔），否则满刀扎入。
2. 刀心轨道半径 = (目标孔径 − 刀径) / 2，**不是底孔半径**。
3. 配合 `cnc-ellipse-comp`：设备失圆时用椭圆轨迹替代正圆。
4. 每圈轴向进给 ≤ 0.5~1mm，铝可大、钢小。
5. **【关键安全】螺旋走完必须先 `G1 X{cx} Y{cy}`（进给 G01）退回圆心，再 `G0` 提刀到安全高度**，然后才移动下一孔。禁止在偏心位置（轨道外圈）直接提刀——刀尖贴着孔壁，直接 Z 向提刀会刮伤孔壁/拉毛表面。

## 示例

D4 铣刀把 φ4.5 扩到 φ5.2，孔心 X14，Z-5→-10：

```
R = (5.2 - 4.0)/2 = 0.6
G0 X14.0 Y0.
G1 Z-5.0 F100
G1 X14.6 Y0.          # 切入轨道半径 0.6
（螺旋 10 圈，Z 逐圈 -0.5）
G1 X14.0 Y0.          # 退回中心
```
