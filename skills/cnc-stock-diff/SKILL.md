# CNC 毛坯-成品差异计算与坐标感知

根据毛坯模型和成品模型，计算「需要被加工去除的材料」，并读取成品模型的工件坐标位置，帮助快速理解如何加工。

## 前置条件

1. **毛坯模型**：STEP/STP/BREP/IGES 文件路径。
2. **成品模型**：STEP/STP/BREP/IGES 文件路径（零件）。
3. 成品模型可能已在 qizhouCNC_CAM 模型视窗里被用户设置了位置（位移/旋转），这些位置参数已持久化，可通过工具读取。

## 可用工具

- `cam_stock_difference`：布尔差 `毛坯 − 成品`，返回待去除材料的体积、包围盒、面/边数量。
- `cam_get_model_pose`：读取成品模型当前的工件坐标位置参数（位移/旋转）。
- `cam_inspect_model`：读取模型面/边几何摘要（辅助理解差异区域）。

## 工作流程

### 1. 读取成品模型位置参数
调用 `cam_get_model_pose`（`path` = 成品模型路径），得到 `{ translate:[x,y,z] mm, rotate:[rx,ry,rz] deg }` 或 `null`（未设置位置 = 恒等）。

### 2. 布尔差计算
调用 `cam_stock_difference`（`stock` = 毛坯路径，`part` = 成品路径）：
- `volume`：待去除材料的体积（mm³）。
- `bounds`：待去除材料的包围盒。
- `empty`：true 表示毛坯已经等于成品，无需加工。
- 完整的待去除区域三角网格场景可通过 `/dsh-cam/stock-diff` 路由获取（供视窗叠加显示）。

### 3. 解读结果并汇报
输出一份简明的加工余量分析：
- 待去除材料总体积（mm³）；
- 待去除区域的包围盒尺寸（长宽高，即最大加工范围）；
- 结合成品模型位置参数，说明工件在机床坐标系中的位置与姿态；
- 若 `empty=true`，说明毛坯与成品一致，无需去除材料。

## 关键约束

- **布尔差方向**：`毛坯 − 成品`（去掉成品后剩下的材料 = 待加工去除）。不要反过来。
- **路径**：stock 和 part 都必须是真实存在的模型文件。
- **坐标感知**：成品模型的位置参数是用户在模型视窗「应用到位」时保存的；若为 null，说明尚未设置位置，工件在原点恒等姿态。
- 布尔差依赖 FreeCAD，若未安装会报错——提示用户安装或配置 freecadBin 路径。
- 结果体积可能很大，汇报时用 mm³ 并换算成立方厘米（1 cm³ = 1000 mm³）帮助理解。
