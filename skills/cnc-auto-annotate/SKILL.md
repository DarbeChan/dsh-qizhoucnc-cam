# CNC 自动标注（按工艺卡标注刀具与坐标系）

根据工艺卡，把「哪个面/边用什么刀具、什么坐标系」自动写到成品模型的标注上，让 qizhouCNC_CAM 的模型视窗里直接看到每个加工位置的刀号与坐标系。

## 前置条件

1. **成品模型**：STEP/STP/BREP/IGES 文件路径。
2. **工艺卡**：用户提供，或本会话已用 `cnc-process-card` skill 生成。若没有，先提示用户提供，或先用 `cnc-process-card` 生成。
3. 标注写入模型的识别文件（`~/.dsh/storages/dsh-cam-features.json`），在 qizhouCNC_CAM 模型视窗左侧列表可见。

## 工作流程

### 1. 读模型几何
调用 `cam_inspect_model`（参数 `path` = 模型路径），得到面/边摘要列表：
- **面**（face）：`{ id, type, radius, axis, area, center, shapeKey }`
  - `Cylinder`（圆柱面）→ 孔/外圆，`radius` = 半径
  - `Plane`（平面）→ 铣面/槽底，看 `area`（面积）与 `center`
  - `Cone` / `Toroid` / `Sphere` → 倒角/圆角/球面
- **边**（edge）：`{ id, type, radius, shapeKey }`，圆边 `radius` = 圆半径。

### 2. 逐项匹配工艺卡
对工艺卡里每个工步（刀号 + 加工内容 + 尺寸），在面/边里找对应几何：

| 工艺卡里的加工项 | 匹配的面/边几何 |
|---|---|
| 钻孔 Φ8 | 半径 = 4 的 `Cylinder` 面（内孔） |
| 铣螺纹 M6×1.0 | 半径 ≈ 底孔半径（M6 底孔约 Φ5，半径 2.5）的 `Cylinder` 面；或按工艺卡底孔尺寸 |
| 铣平面/槽底 | 面积匹配的 `Plane` 面 |
| 倒角 | `Cone` 面（半角≈45°） |
| 圆弧槽 | 半径匹配的 `Toroid` 面或圆边 |
| 外圆 | 半径匹配的 `Cylinder` 面（但轴向外） |

**匹配原则**：
- 半径按 `工艺卡直径 ÷ 2` 换算后对比 `radius`，取最接近的（容差 ±0.2mm，找不到就放宽）。
- 多个同尺寸特征（如 4 个 Φ8 孔）→ 用同一个 `shapeKey` 分组，一次性批量标注。
- 匹配不上的（不规则特征）→ **列出来让用户手动点面确认**，不要乱猜。

### 3. 写标注
对每个匹配结果调用 `cam_annotate_feature`：
- `path`：模型路径
- `name`：简短名称，如「Φ8 定位孔」「M6 螺纹」「铣平面」
- `kind`：`face` 或 `edge`
- `refId`（单个）或 `refIds`（批量，多个 id 数组）
- `tool`：刀号与规格，如「T3=Φ6.9 定心钻」
- `coordinate`：坐标系，如「G54」
- `note`：加工内容补充，如「钻底孔 深10」

`tool`、`coordinate`、`note` 会自动拼成标注的备注，显示在模型视窗左侧。

### 4. 汇报结果
完成后列出：标注了哪些特征、每个对应的刀号/坐标系、以及**哪些特征无法自动匹配需要用户手动确认**。

## 关键约束

- **不编造面/边 id**：id 必须来自 `cam_inspect_model` 的返回，不能自己假设。
- **半径换算**：工艺卡常给直径（Φ），`radius = 直径 ÷ 2`；螺纹用底孔直径算半径（不是大径）。
- **批量优先**：多个相同特征（同 shapeKey）用一次 `cam_annotate_feature` + `refIds` 批量写，避免重复。
- **兜底**：不规则或匹配不上的特征，明确告诉用户「请手动在模型视窗点选」，不要强行标注。
- 坐标系按工艺卡里写的 G54~G59；若工艺卡没写，默认 G54 并注明「未指定，默认 G54」。
