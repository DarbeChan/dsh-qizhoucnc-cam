# 螺纹铣削（Thread Milling）

用螺纹铣刀在预钻底孔内铣出内螺纹。核心是多刀径向切入 + 螺旋插补，刀心轨道半径 = (螺纹大径 − 刀径)/2。

## 触发场景

- 铣牙 / 铣内螺纹（M5、M6、M8…）
- 用户提供螺纹铣刀（刃直径、螺距）要求铣螺纹

## 输入

| 参数 | 含义 | 示例 |
|---|---|---|
| nom_d | 螺纹公称大径 | 5.0 (M5) |
| tool_d | 铣牙刀刃直径 | 3.9 |
| pitch | 螺距 | 0.8 |
| z0, z1 | 螺纹起止深度（决定方向） | Z1→Z-15 |
| 分刀 | 径向切入比例序列 | 试刀1% / 50% / 100% |
| F / S | 进给 / 转速 | 300 / 3000 |

## 输出

- 螺纹螺旋 G01（或 G02/G03 螺旋）程序段

## 生成规则

### 1. 刀心轨道半径

```
R = (nom_d - tool_d) / 2
```

> 例：M5 刀径 3.9 → R = (5.0−3.9)/2 = 0.55；M6 刀径 4.5 → R = (6.0−4.5)/2 = 0.75。

### 2. 分刀策略（径向逐步切入）

- 试刀 1%（全深绕一圈，检查）
- 正式 50% → 100%（或 60% → 100% → 光刀）
- 每刀：径向切入到 `R×比例`，螺旋走完整个螺纹深度。

### 3. 方向（右旋内螺纹，默认正常丝）

- **默认正常丝 = 右旋**。除非用户单独说明「反丝」，否则一律按右旋铣。
- **右旋内螺纹**：自上而下 G02（下铣逆铣排屑向下）、自下而上 G03（上铣顺铣精修），M03 正转。
- **反丝 = 左旋**：螺旋角度反向（θ 取负），即反转螺旋旋向；其余（分刀、深度、抬刀）不变。
- 圈数 = |z1−z0| ÷ 螺距；不足一圈按角度换算。

> **务必向用户确认**：多孔螺纹时逐个问清哪个是反丝；不确认就默认右旋，并在注释里标注旋向（如「孔2 左旋反丝」）。

### 4. 螺旋逐点展开（设备不支持宏时）

```
for ratio in 分刀比例:
    Rr = R * ratio
    G0 X{cx} Y{cy}            # 孔心
    G1 Z{z0}
    G1 X{cx+Rr} Y{cy}         # 切入
    for k in 0..圈数*每圈点数:
        θ = 2π * k / 每圈点数  (方向决定正负)
        z = z0 + (z1-z0) * k / 总点数
        G1 X{cx+Rr·cosθ} Y{cy+Rr·sinθ} Z{z}
    G1 X{cx} Y{cy}            # 退回中心
```

## 关键约束

1. **底孔必须先钻好**（底孔直径 < 螺纹小径或按标准底孔表），刀径 < 底孔才能从孔心下刀。
2. **刀心半径 = (大径 − 刀径)/2**，不是底孔半径。
3. **刃径必须用实际值**（实测或刀盒标注），不得用名义刃径；编程大径默认用公称大径，**不盲目叠加直径补偿**。实例教训：M4 铣牙刀名义刃径 3.0、实际 3.03，若按 3.0 算 R=0.5 又叠 +0.08 直径补偿 → 内螺纹铣得过松；正确满牙轨道 R=(4.0−3.03)/2=0.485，不加补偿。
4. 方向：**默认右旋（正常丝）**；只有用户明确说「反丝」才用左旋（螺旋角度反向）。
5. 配合 `cnc-ellipse-comp`：设备失圆时用椭圆轨迹（X 半轴 +0.1）。
6. 铣牙刀从孔中心下刀，避免满刀切入。
7. **【关键安全·内螺纹】螺旋走完必须先 `G1 X{cx} Y{cy}`（进给 G01）退回圆心，再 `G0` 提刀**。禁止在偏心位置（轨道外圈）直接提刀——刀尖仍在螺纹/孔壁里，直接 Z 向提刀会刮伤已铣好的螺纹面。**每一刀**（试刀/粗/精/光刀）结束都要「回圆心 → 提刀」，不是只在最后一刀。
   > **外螺纹逻辑相反**：外螺纹铣圆柱外表面，圆心是工件实体，**禁止回圆心**（会撞工件）。刀心轨道在圆柱外侧，走完螺旋后刀具已在工件外侧的空中，**直接 G0 提刀**即可；进刀、退刀都从工件外侧进行。

## 内螺纹 vs 外螺纹（核心差异）

本技能默认讲**内螺纹**；用户要求铣**外螺纹**（圆柱外表面的螺纹）时，以下逻辑必须反转：

| 项目 | 内螺纹 | 外螺纹 |
|---|---|---|
| 加工对象 | 孔内壁 | 圆柱外表面 |
| 圆心性质 | **空**（底孔） | **实体**（工件本体） |
| 刀心轨道半径 R | `(大径 − 刀径)/2` | `(大径 + 刀径)/2` |
| 下刀位置 | 从孔心（空）下刀 | 从工件外侧（空）下刀，**禁止过圆心** |
| 螺旋走完后 | 先回圆心（G1）再提刀 | 已在工件外侧空中，直接 G0 提刀 |
| 禁止动作 | 偏心处直接提刀（刮螺纹） | 回圆心 / 穿过实体（撞刀） |
| 旋向 | 右旋默认 G02下/G03上 | 同上（右旋默认） |

> 判断口诀：**「空的那边」才能进刀/退刀**。内螺纹空在圆心 → 走完回圆心提刀；外螺纹空在圆周外 → 走完在外侧直接提刀。

## 示例

M5（刀径 3.9、螺距 0.8），孔心 X14，Z1→Z-15，2 刀 50%/100%：

```
R = (5.0-3.9)/2 = 0.55
第1刀 径向50%: Rr=0.275
  切入 X14.275 → 螺旋 Z1→-15（下铣）
第2刀 径向100%: Rr=0.55
  切入 X14.55 → 螺旋 Z1→-15
```
