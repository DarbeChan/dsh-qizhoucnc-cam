# 往复式层切铣削（Raster Milling）

用平底铣刀按「每层固定切深 + 每层往复走刀」的方式铣平面或直槽。适用于直壁、平底特征的粗铣与精铣。

## 触发场景

- 铣平面 / 铣直槽 / 往复式铣削
- 用户明确「往复式、每层 0.5mm」这类层切参数

## 输入

| 参数 | 含义 | 示例 |
|---|---|---|
| x0, x1 | 走刀方向范围 | X-16 ~ X16 |
| y0, y1 | 横向步进范围 | Y-8 ~ Y8 |
| z_start | 起始深度 | Z0 |
| z_end | 终止深度 | Z-5 |
| step_z | 每层切深 | 0.5 |
| step_xy | 行距（= 刀径 × 0.7 左右） | 5.6 |
| F | 进给 | 600 |
| S | 转速 | 4500 |

## 输出

- 逐层往复的 G01 铣削程序段

## 生成规则

```
z = z_start - step_z
while z >= z_end:
    G1 Z{z} F{F}              # 下刀到本层
    y = y0; dir = +1
    while y <= y1:
        x 从 (x0→x1) 或 (x1→x0)   # 交替方向
        G1 X{x} Y{y}
        y += step_xy
        dir = -dir
    z -= step_z
```

伪代码（交替方向走刀）：

```
for z in 每层:
    下刀到 z
    y = y_min
    方向 = 向右
    while y <= y_max:
        if 方向向右: G1 X=x_max  (从 x_min 起)
        else:        G1 X=x_min  (从 x_max 起)
        y += 行距
        方向 = -方向
```

## 关键约束

1. **行距 ≤ 刀径 × 0.8**，避免留岛；精铣行距更小。
2. **每层先下刀到位再横向走刀**，避免斜向拉刀。
3. 直槽端壁：刀心**收进一个刀半径**，防止过切端壁。
4. 往复方向交替（Z 字形），不要每层都从同一侧起刀（省空行程、减少单向进给痕迹）。
5. 下刀点从槽/平面外侧或已清空区域进入，避免满刀直接扎入。

## 示例

D8 铣刀，X-16~16、Y 单线（槽宽等于刀径），每层 0.5：

```
G1 Z-0.50 F600
G1 X16. F600
G1 Z-1.00 F600
G1 X-16. F600
G1 Z-1.50 F600
G1 X16. F600
```
